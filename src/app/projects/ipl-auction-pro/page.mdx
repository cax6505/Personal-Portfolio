# Case Study: DraftForge — IPL Mega Auction Simulator

## Real-Time Multiplayer Cricket Manager Draft Room

**DraftForge** is a real-time, multi-client cricket manager draft room simulator built for IPL strategy gaming. It mirrors the exact mechanics, financial constraints, and fast-paced excitement of the official **IPL Mega Auction**.

**[GitHub Repository →](https://github.com/cax6505/IPL-Auction-simulator)**

---

### Tech Stack
*   **Frontend**: Next.js, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons
*   **Database & Realtime**: Supabase, PostgreSQL, Supabase Realtime Channels (WebSockets)
*   **Concurrency & Auth**: PostgreSQL RPC Database Functions (`execute_bid`), Row-Level Security (RLS)

---

### The Problem
During high-frequency multiplayer bidding wars, state synchronization conflicts frequently occur when multiple users attempt to bid on the same player in the exact same millisecond:
1.  **Race Conditions**: Simultaneous client-side requests cause double-deductions, out-of-order bid logs, or budget overdrafts.
2.  **Latency Delays**: Traditional HTTP polling or un-optimized socket loops create sluggish 1s+ delays that ruin live auction intensity.
3.  **Complex Multi-Rule Enforcement**: Real-time validation of dynamic bidding ladders (e.g. ₹5L to ₹50L step increments), total purse ceilings (₹120 Cr), overseas player quotas (max 8), and minimum squad counts (18–25 players).

---

### Key Engineering Solutions & Architecture

<RealtimeBidSequence />

#### 1. Atomic Concurrency Protection via PostgreSQL RPC (`execute_bid`)
To eliminate race conditions, bid validation and state execution are handled inside a PostgreSQL Database Function (RPC).
*   Locks the active player row instantly using `SELECT ... FOR UPDATE`.
*   Verifies bid increment validity against official IPL ladder thresholds.
*   Validates purse capacity and enforces overseas quota limits before updating database state.
*   Commits atomically or rolls back with precise error diagnostics if rule checks fail.

#### 2. Sub-200ms State Sync via Supabase Realtime
Connected client war rooms subscribe to Supabase Realtime WebSocket broadcast channels. As soon as a transaction commits in PostgreSQL, change events trigger instant WebSocket broadcasts to all connected clients in the lobby. Synchronized state updates achieve sub-200ms latency across multi-user sessions.

#### 3. Official IPL Mechanics & Draft Modes
*   **Official Bidding Ladder**: Automatically scales bid increments dynamically (₹5L/₹10L under ₹2 Cr, ₹25L up to ₹5 Cr, and ₹50L above ₹5 Cr).
*   **Franchise Management**: Allows users to host public rooms or create 6-digit private code war rooms to claim any of the 10 official IPL franchises.
*   **Multiple Game Modes**: Full Mega Auction, Mock 2026 Draft, and Retired Legends Draft pools.
